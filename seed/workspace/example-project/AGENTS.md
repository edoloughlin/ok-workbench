# Example project instructions

Read this file after the workspace-level `AGENTS.md`. This project uses the
standard workspace conventions without additional domain-specific rules.

For substantive work, read `index.md`, then `status.md`, then the newest
relevant entries in `log.md`. Keep the task list and dated reviews aligned with
the current status; update the log before recording a completed outcome.

Treat the starter brief and tasks as examples, not evidence of the user's goals
or permission to execute a backlog. When the user supplies a real goal, propose
a checkable success criterion and the highest-value next step. Flag unsupported
assumptions and carry authorized work through to a verified result. Keep
recommendations separate from decisions the user has accepted.
